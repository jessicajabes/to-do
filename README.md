# Rastreador de Hábitos

Projeto pessoal de estudo para revisitar e consolidar conceitos de desenvolvimento web que uso no dia a dia de trabalho.

## Objetivo

Dominar de verdade as tecnologias que já utilizo — a ponto de escrever o código sozinha, sem consulta. Todo o código deste repositório foi escrito à mão. A inteligência artificial foi usada apenas para tirar dúvidas conceituais, nunca para gerar código.

## Funcionalidades

- Adicionar e remover hábitos
- Marcar/desmarcar um hábito como feito no dia
- Calcular sequência de dias consecutivos (streak)
- Persistência dos dados entre sessões

## Roteiro de fases

O mesmo projeto evolui ao longo das fases, sem reescrever do zero:

1. **HTML + CSS + JS puro** — persistência em `localStorage` ✅
2. Node.js — API REST com Express
3. React — front em componentes e hooks
4. Redux + Redux-Saga — estado global e efeitos colaterais
5. Testes com Jest
6. TypeScript
7. Arquitetura hexagonal
8. Docker
9. BFF + Redis
10. CI/CD
11. AWS
12. Observabilidade
13. Kafka
14. Next.js
